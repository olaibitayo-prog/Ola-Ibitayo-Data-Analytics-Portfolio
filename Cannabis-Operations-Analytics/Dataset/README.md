# Dataset Documentation

## Overview

This folder contains the full cannabis operations dataset used for this analytics project.

The dataset contains approximately 250,000 operational records designed to simulate a real-world cannabis production and business environment.

Note:
Due to the dataset size, GitHub may not display a browser preview. The file can be downloaded and analyzed locally.

---

## Dataset Contents

The dataset includes:

- Production batch information
- Cannabis strain data
- Cultivation room performance
- Product categories
- Inventory metrics
- Quality control indicators
- Sales and revenue information

---

## Purpose of Dataset

This dataset was used to perform:

- Data cleaning
- SQL analysis
- KPI development
- Operational reporting
- Power BI dashboard creation

---

## Data Quality Challenges

The dataset contained real-world data quality issues including:

- Missing values
- Duplicate records
- Formatting inconsistencies
- Data validation issues

These issues were resolved during the data preparation stage.
