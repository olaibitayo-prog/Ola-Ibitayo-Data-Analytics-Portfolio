# Dataset

This folder contains the full cannabis operations dataset used for analysis.

Note: The CSV file may be too large to preview directly on GitHub. To view or use the dataset, click the file and select **Download raw file**.

The dataset contains approximately 250,000 rows and supports analysis of:

- Production batches
- Cannabis strains
- Cultivation rooms
- Inventory
- Revenue
- Quality control results
- Sales performance# Dataset


The data was prepared for SQL analysis, Excel exploration, and Power BI reporting.
