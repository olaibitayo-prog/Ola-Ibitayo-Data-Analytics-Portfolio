# Healthcare Performance Analytics Dashboard

## Project Overview

This project analyzes healthcare operational data to identify trends, measure performance, and support data-driven decision making.

The goal is to simulate how healthcare organizations use analytics to improve service delivery and monitor key performance indicators.

---

## Business Questions

This project answers:

1. Which programs have the highest demand?
2. What factors impact service wait times?
3. How efficiently are resources being used?
4. What operational areas require improvement?
